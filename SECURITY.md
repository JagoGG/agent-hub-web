# Seguridad

## Versiones admitidas

Solo la versión publicada más reciente del portal recibe correcciones de
seguridad.

## Reporte responsable

No publiques vulnerabilidades, credenciales, datos personales ni pruebas de
concepto sensibles en un issue público. Usa el canal privado de seguridad del
repositorio:

<https://github.com/JagoGG/agent-hub-web/security/advisories/new>

Incluye una descripción breve, el impacto, los pasos mínimos para reproducir el
problema y una corrección sugerida si la conoces. Utiliza datos ficticios y
elimina tokens, cookies, rutas locales y cualquier información de terceros.

No realices pruebas destructivas, ingeniería social, denegación de servicio ni
acceso a cuentas ajenas.
