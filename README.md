# Agent Hub Web

Portal público de Agent Hub para conocer el producto, revisar su modelo de
seguridad y acceder a las funciones de cuenta cuando la infraestructura de
producción esté habilitada y verificada.

Este snapshot está en modo informativo: registro, inicio de sesión y descargas
permanecen bloqueados. No intenta conectarse a un backend ni presenta una cuenta
de demostración como si fuera real.

El repositorio público contiene únicamente HTML, CSS, JavaScript y recursos de
marca compilados. No incluye el núcleo de escritorio, conversaciones, datos de
agentes, credenciales, variables privadas, documentación interna ni historial
del repositorio de desarrollo.

Portal público principal: <https://agent-hub-jagogg.jagogg.chatgpt.site/>

Snapshot estático verificable: <https://jagogg.github.io/agent-hub-web/>

La activación de cuentas exige que identidad, correo transaccional, anti-bot,
OAuth y almacenamiento hayan superado la auditoría de producción. Hasta
entonces ambos sitios fallan cerrado y no recopilan datos de registro.

Consulta [SECURITY.md](SECURITY.md) para informar una vulnerabilidad de forma
confidencial.
